PROBLEM STATEMENT & METHODOLOGY RESEARCH SUMMARY

In large-scale inter-domain networks, standard BGP-4 Path Vector routing suffers from two fundamental bottlenecks: (1) Rapid routing table inflation ($O(N \times P)$ growth requiring substantial TCAM memory), and (2) Reconvergence message storms following topological perturbations (path hunting).

This simulation engine evaluates multi-scale topologies ($N = 10 \to 1000$ ASes) under deterministic discrete-event conditions. It verifies that a combined Hybrid Optimization Suite (CIDR prefix aggregation, stub default route injection, and AS-path compression) substantially cuts router memory footprint and table entries while preserving the fundamental 100.0% end-to-end reachability invariant verified via Longest Prefix Match (LPM) packet forwarding.

OPTIMIZATION MECHANISM

How Hybrid Optimization Operates:

1. Stub Default Injection: Single-homed enterprise ASes only have one exit gateway. Replacing the entire global forwarding table with 0.0.0.0/0 cuts table size to 1 entry without dropping packets.

2. CIDR Prefix Summarization: Contiguous /24 subnets (e.g. 10.0.1.0/24 and 10.0.2.0/24) originating from the same upstream provider are combined into supernets (10.0.0.0/22).

3. AS-Path Compression: Non-transit edge routers only require the next-hop IP, discarding the extended transitive AS_PATH in hardware FIB storage.
